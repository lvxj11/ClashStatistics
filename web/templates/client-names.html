客户端名称

为客户端 IP 指定一个便于识别的名称，可选填备注。名称只是辅助信息： IP 仍是主键，排序、搜索、明细下钻都按 IP 进行。 统计页与在线状态页会在 IP 后面以 IP (名称) 的形式显示， 备注仅作鼠标悬浮提示。

手动配置始终优先：手动名称非空时，自动识别的结果一律忽略（但保留，清除手动后可回退）。 自动识别（DHCP option 12 优先于 mDNS，另有连接元数据）只是兜底，不保证一定能获取到。
