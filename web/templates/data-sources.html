数据源定义只认数据库这一张表，改动即时生效；全新部署初始 0 数据源，不做任何播种。系统级配置（端口 / 日志 / 保留天数）在 config.toml 或环境变量里，与数据源无关。 三个开关各管一件事、互不影响：采集只控制是否采集落库；汇总只控制该 Clash 源是否进入目标 / 客户端统计（IPFIX 不适用，仅用于在线状态）；在线默认为单选，决定在线状态页跟随哪个源。三个开关已放在一起、紧跟操作列，目标 / 客户端统计统一在本页按「汇总」配置，不在统计页分别切换，避免数据不配套。

Clash 凭据可填环境变量名，或直接填密钥（轻量混淆后存本表、不回显）；环境变量优先，页面与接口都不回显明文。状态列是运行时有效性：由采集动作本身推导（Clash 连不上、IPFIX 断流即警告），不是额外探测，每 60 秒自动刷新；采集关闭的源显示灰「已停用」，不代表源坏了。
