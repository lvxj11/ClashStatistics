# Clash Statistics

通过 Clash API **只读**获取连接信息、做统计与回溯，并以网页呈现的应用。

> **一句话：它只统计，不管理。** 不修改任何 Clash 配置，只读取 `/connections`，落 SQLite 后可按天回溯。

两个核心用途：**流量归因**（谁 / 哪个目标用了多少流量、走了哪条线路），以及**使用时段监控**（按天看每个设备的在线时段与并发强度，观察某设备是否在不应使用的时间仍有连接）。

## 快速开始

```bash
go build -o dist/clash-statistics .
cd dist && ./clash-statistics
# 浏览器打开 http://localhost:8080
```

首次运行会在**当前工作目录**生成 `data/config.toml`，按实际情况填写 `[clash]` 的 `host` / `secret` 即可；也可用环境变量逐项覆盖，详见 [配置与部署](docs/configuration.md)。

> 运行时文件（数据库、日志、配置）都在当前工作目录的 `data/` 下，所以建议在 `dist/` 里运行，项目根目录只留源码。

## 功能

- 目标统计：按访问目标（域名 / IP）聚合，下钻到 客户端 × 线路 × 规则 明细
- 客户端统计：按客户端（源 IP）聚合，下钻到 目标 × 线路 × 规则 明细
- 在线状态：按天展示每个客户端的在线时段与并发连接强度（时间热度图）
- 客户端名称：为 IP 指定名称与备注，另有可选的 DHCP option 12 / mDNS 自动识别兜底
- 服务端搜索 / 排序 / 时间范围筛选，明细弹窗同样支持
- 数据落 SQLite，默认保留 30 天；深浅主题、响应式、实时刷新
- 支持 `config.toml` 与环境变量两种配置方式
